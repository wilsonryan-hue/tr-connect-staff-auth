Add to Home Screen

Put the staff desk on your phone. The icon name is TR Connect. This page is on the staff server. It is not the public website.

Safari on iPhone or iPad

  1. Open this desk in Safari.
  2. Tap the Share button. It is the square with an arrow pointing up.
  3. Scroll the sheet and tap Add to Home Screen.
  4. Tap Add. The home screen icon reads TR Connect.

Chrome

  1. Open this desk in Chrome.
  2. On a phone, tap the menu (three dots). On a computer, open the Chrome menu, or use the install icon in the address bar.
  3. Tap Add to Home screen. If Chrome offers Install app, tap that instead.
  4. Confirm. The name is Treun Roc Connect. The short name on the icon is TR Connect.

Open TR Connect from the home screen, sign in, and the desk opens Home.
